A **React Native Expo** application designed to manage employee-related functionalities, including a dashboard, notifications, and profile management.

---

## Features
- **Dashboard Screen:** Displays key metrics and statistics for employees.
- **Notifications Screen:** Lists notifications related to the employee's work and updates.
- **Profile Management:** Allows employees to view and update their profile details.
- **Typescript used**
- **Bottom tab navigator**
- **Font awesome icon library**

## Installation and Setup
Follow these steps to set up the app on your local environment:

### Prerequisites
- Node.js (latest stable version recommended)
- Expo CLI installed globally (`npm install -g expo-cli`)

### Steps
1. Clone the repository:
   ```bash
   git clone https://github.com/ershubhamgupta1/mobile-app-employee-management
   cd mobile-app-employee-management
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   expo start
   ```

4. Download the **Expo Go** app on your physical devices:
   - **Android**: [Google Play Store](https://play.google.com/store/apps/details?id=host.exp.exponent)
   - **iOS**: [App Store](https://apps.apple.com/app/expo-go/id982107779)

5. Scan the QR code displayed in the terminal or Expo web interface using the **Expo Go** app.

6. The app will open on your physical device.

### Running on a Physical Device
- **Android**: Open Expo Go, scan the QR code, and the app will load.
- **iPhone**: Open the Camera app, scan the QR code, and follow the link to Expo Go.
